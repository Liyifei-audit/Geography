# Geography
> 3D visualization of Earth's movements for junior and senior high school geography

[![GitHub Pages](https://img.shields.io/badge/demo-online-green)](https://Lilipeer.github.io/Geography)

## 📖 项目介绍
本项目是面向初高中地理教学的**地球运动3D可视化网页**，使用前端3D技术模拟地球自转、公转等地理现象，直观展示地理课堂抽象知识点。
后续计划添加洋流、昼夜长短变化、四季形成等更多地理模拟内容。

## 🔗 在线演示
👉 在线预览地址：https://Lilipeer.github.io/Geography
不需要任何环境，浏览器直接打开即可体验3D地球。

## 🚀 本地运行
1. Clone 仓库到本地
```bash
git clone https://github.com/Lilipeer/Geography.git
cd Geography
```

2. 直接打开项目内的 `index.html` 文件，即可在浏览器运行。

> 
> 本项目纯前端，无需后端、无需安装依赖。

## 🛠️ 技术栈

- HTML / CSS / JavaScript
- WebGL 3D 可视化

## ✨ 功能清单

- 地球基础 3D 模型，地球自转、公转模拟
- 洋流系统可视化（开发中）
- 昼夜半球、晨昏线模拟
- 四季与正午太阳高度演示
