# 太阳直射点视觉设计

## 目标

让太阳直射点在地球表面上具有清晰、稳定、可解释的视觉表达，并与红色观测点区分开；同时让太阳光线具备明确的照射方向和柔和层次。

## 设计

- 直射点使用金黄色核心、半透明光晕、双层脉冲环和短法线标记，位置仍严格由太阳方向计算。
- 直射点旁显示动态经纬度标签，标注“太阳直射点”及当前纬度、经度。
- 太阳光线由柔和外层、核心线和靠近地球表面的方向箭头组成；线段端点仍是太阳中心到直射点。
- 图例同时显示：金黄色为太阳直射点，红色为观测点，避免把观测点误认为直射点。
- 动画仅改变视觉透明度、环半径和箭头位置，不改变天文坐标或时间模型。

## 验收标准

1. 直射点坐标与数据面板 `d-sublat` / `d-sublon` 一致。
2. 直射点在桌面和移动尺寸下都能辨认，标签不遮挡地球主体。
3. 光线方向从太阳指向直射点，箭头尖端落在地球表面外侧。
4. 红色观测点和金黄色直射点在图例中有独立说明。
5. 页面无 `pageerror`，现有天文准确性测试保持通过。
