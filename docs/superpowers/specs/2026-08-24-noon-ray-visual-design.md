# 正午太阳高度光线视觉优化

## 目标

在不改变正午太阳高度的计算、按钮交互、数据标签和其他图层的前提下，让演示中的两条方向线与中间角度弧线更自然、更易读。

## 方案

- 太阳入射方向：保留原始端点和方向，使用主光束、柔和外晕和渐亮端点组合，颜色仍为暖黄色。
- 天顶方向：保留原始端点和方向，使用主光束、低透明度外晕和冷色端点组合，颜色仍为青蓝色。
- 正午高度弧：保留同一夹角和半径，使用平滑分段曲线、双层透明描边和轻微脉冲，避免粗重折线感。
- 性能与兼容：继续使用现有 Three.js 几何和材质，不增加网络依赖；所有对象仍挂在 `noonDemoGroup`，可随现有开关统一显示/隐藏。

## 验证

- 点击“正午太阳高度”后，两个方向、夹角和角度数值仍随观测点和日期更新。
- 切换视角、关闭演示、重置参数后，演示层正确隐藏并恢复其他图层。
- 浏览器无页面错误，现有准确性测试继续通过。
