# Implementation Plan: 地球教学工具优先级升级

## Overview

把当前视频效果 Demo 升级为可用于课堂探索的交互工具，优先解决仿真时间一致性、时间轴控制和地理探索能力，同时保持单文件离线运行特性。

## Architecture Decisions

- 继续保持 `index.html` 可双击运行，不引入运行时依赖；新增数据放在 `assets/`。
- 增加“真实时间锁定”逻辑，地球自转角由模拟 UTC 时间推导；保留独立自转/公转演示开关作为教学模式。
- 地理探索先采用小型本地 GeoJSON 与城市索引，避免首次加载依赖在线 API；完整高精度边界作为后续数据包升级。
- 所有 UI 改动沿用现有深色蓝色控制台，桌面与移动端共享控件。

## Task List

### Phase 1: 时间模型

- [ ] Task 1: 建立 UTC 与恒星时自转角的统一计算，并增加真实时间模式开关。
- [ ] Task 2: 增加日期时间输入、时间轴拖动、步进和回到现在控制。

### Checkpoint: 时间模型

- [ ] 节气跳转、时间轴拖动和真实时间模式互相一致。
- [ ] 3D 直射点与数据面板的太阳位置一致。

### Phase 2: 地理探索

- [ ] Task 3: 下载并整理本地 GeoJSON/城市索引及离线地理贴图资源。
- [ ] Task 4: 增加国家边界、城市搜索、点击拾取与地点信息面板。

### Checkpoint: 探索能力

- [ ] 能搜索并定位北京、伦敦、纽约等城市。
- [ ] 能显示国家边界和当前经纬度。
- [ ] 断网打开仍可使用核心探索功能。

### Phase 3: 工程质量

- [ ] Task 5: 降低每帧几何分配，补充键盘/ARIA 状态。
- [ ] Task 6: 增加浏览器冒烟验证并更新开发文档。

### Checkpoint: Complete

- [ ] 桌面 1280px、平板 768px、手机 390px 通过验收。
- [ ] 页面无未捕获运行时错误。

## Risks and Mitigations

| Risk | Impact | Mitigation |
| --- | --- | --- |
| 精确国家边界数据过大 | 首屏变慢 | 先使用简化 GeoJSON，按需加载详细数据 |
| 时间锁定改变现有演示行为 | 教学流程回归 | 默认保留当前独立模式，真实模式显式切换 |
| 外部资源失效 | 离线功能不可用 | 关键贴图和基础地理数据全部本地化 |
